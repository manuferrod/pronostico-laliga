Cómo funciona

Cuatro pasos en Python, del dato público al pronóstico. Se ejecutan en orden cada jornada y cada uno comprueba sus datos antes de pasar al siguiente.

  1. Extracción

    8.109 partidos

    Cinco fuentes públicas desde 2005: football-data (resultados y cuotas), Understat y SofaScore (goles esperados y estadística), ClubElo (nivel de cada club) y Transfermarkt (valor de plantilla).

  2. Limpieza y variables

    171.206 datos

    La estadística de 5.069 partidos se convierte en rachas, promedios y tendencias. Ninguna usa lo que pasa en el propio partido.

  3. Preprocesado

    252 variables

    Se comparan los dos equipos, se tratan los huecos y queda una tabla de 7.739 partidos lista para entrenar.

  4. Modelado

    8 variables finales

    Regresión logística multinomial, reentrenada antes de cada fecha de partidos. Es un modelo sencillo que se puede explicar.

Cada fecha se pronostica con su pasado

Para pronosticar un día se entrena con los 1.520 partidos anteriores (cuatro temporadas). Los 380 últimos pesan el triple. Al día siguiente la ventana avanza y se repite.

De la estadística a la señal

Un modelo no entiende de fútbol: hay que traducírselo. Cada variable nace de una pregunta. Estas son cuatro de las 252 creadas, con los datos de antes de la jornada 14.

De 252 candidatas a 8

Cada cuadro es una variable creada. En amarillo, las que se quedan.

Cómo se optimiza

Paso a paso, y siempre con el examen completo.

  1. Añadir o quitar una

    Se parte de un conjunto pequeño y se prueba cada candidata, de una en una.

  2. Repetir el examen

    Con cada prueba el modelo se vuelve a entrenar y a pronosticar fecha a fecha: 1.665 entrenamientos en el periodo que se ve aquí.

  3. Dos notas a la vez

    Se mira cuánto acierta y cuánto rinde. La diferencia con el conjunto anterior se mide partido a partido.

  4. Quedarse con poco

    Si una variable no aporta, sale. Un modelo pequeño es más estable y se puede explicar.

Las reglas

Un pronóstico solo vale si la prueba es justa. Así se mide este.

Nunca ve el futuro

Para pronosticar un partido, el modelo solo se entrena con los anteriores. Ninguna variable usa lo que pasa en el propio partido.

Mismos partidos, mismas cuotas

El modelo y el favorito de Bet365 se miden en los mismos 4.689 partidos y a la misma cuota: la de apertura, con un margen medio del 5,4 % a favor de la casa.

Se apuesta a todo

Una unidad en cada partido. No se eligen los fáciles ni se cambia la cantidad según la confianza.

Todo se comprueba

Cada paso revisa sus datos antes de dar paso al siguiente, y esta página no se publica si sus cifras no coinciden con las del modelo.

Es una simulación con datos históricos. Las variables se seleccionaron con estas mismas temporadas.
